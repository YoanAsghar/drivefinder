# Controllers

This directory contains ASP.NET Core API controllers that expose HTTP endpoints for the DriveFinder application.

## Files

- **EmbeddingsController.cs** — Controller for embedding-related operations. Accepts text input and returns chunked results with embeddings generated by Ollama.
- **DriveController.cs** — Controller for Google Drive sync operations. Runs a full sync of the whole Drive into the database.
- **SearchController.cs** — Controller for searching indexed documents with a text query.
