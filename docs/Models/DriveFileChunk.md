# DriveFileChunk

## Purpose

The `DriveFileChunk` model represents a single text chunk extracted from a `DriveFile`. Each chunk stores its content, vector embedding, and metadata about the source file so that search results can trace back to the original file in Google Drive.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `Id` | `Guid` | Primary key, auto-generated via `gen_random_uuid()`. |
| `DriveFileId` | `Guid` | Foreign key to the parent `DriveFile`. |
| `DriveFile` | `DriveFile?` | Navigation property to the source `DriveFile`. |
| `Index` | `int` | Zero-based index of the chunk within the source file. |
| `Content` | `string` | The text content of this chunk. |
| `Embedding` | `Vector?` | The 768-dimensional vector embedding generated by Ollama. |
| `FilePath` | `string` | The path/route of the file in Google Drive (e.g., "Documents/Projects/README.md"). |
| `FileName` | `string` | The name of the source file at the time this chunk was created. |
| `MimeType` | `string` | The MIME type of the source file (e.g., "text/plain"). |
| `CreatedAt` | `DateTimeOffset` | Timestamp when this chunk was created. |

## Database

- **Table:** `drive_file_chunks`
- **Indexes:**
  - HNSW index on `Embedding` for cosine similarity search (`vector_cosine_ops`)
  - Composite index on `(DriveFileId, Index)` for fast lookup by file
- **Foreign Key:** `DriveFileId` → `drive_files.Id` with `CASCADE` delete

## Dependencies

- **Pgvector** — Provides the `Vector` type for embedding storage.
- **DriveFinder.Models.DriveFile** — Parent entity this chunk belongs to.
